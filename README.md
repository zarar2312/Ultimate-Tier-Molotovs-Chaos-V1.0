## 📋 V2.2 Update Description

Transform your 7 Days to Die experience with **Ultimate Tier Molotovs V2.2** - the most comprehensive molotov cocktail mod featuring 5 devastating tiers of fiery destruction!

### 🔥 New Features
- **Enhanced Burning Effects**: Optimized burn duration for all tier molotovs
- **Balanced Damage System**: Recalibrated damage values for each tier
- **Visual Improvements**: Enhanced color coding and visual effects
- **Performance Optimization**: More stable and faster performance
- **Server Compatibility**: Full compatibility for multiplayer servers

### ⚡ Technical Improvements
- **Ultimate Tier 1**: Green effect, 380 fire damage, 5 block radius
- **Ultimate Tier 2**: Cyan effect, 460 fire damage, 6 block radius  
- **Ultimate Tier 3**: Yellow effect, 540 fire damage, 8 block radius
- **Ultimate Tier 4**: Purple effect, 620 fire damage, 10 block radius
- **Ultimate Tier 5**: Red effect, 700 fire damage, 15 block radius

### 🛠️ Bug Fixes
- Improved molotov collision detection
- Rebalanced economic values
- Optimized light effects
- Balanced recipe costs

### 📦 Installation
1. Delete existing mod files from your `Mods` folder
2. Copy new V2.2 files to your `Mods` folder
3. Start the game and enjoy!

### 🎯 Features
- **5 Different Tiers**: Each tier delivers more powerful damage and area of effect
- **Progression System**: Compatible with Fireman's Almanac progression
- **Server Friendly**: Only requires server-side installation
- **Multiplayer Compatible**: Seamless experience for all players
- **Workbench Crafting**: All molotovs can be crafted at workbench

### 🔧 System Requirements
- 7 Days to Die v2.2 
- Server-side mod support enabled
- Workbench crafting available

### 🎮 How to Use
1. Craft molotovs at any workbench using cloth, gas, and oil
2. Higher tiers require more resources but deliver devastating results
3. Perfect for clearing zombie hordes and base defense
4. Compatible with existing progression systems
